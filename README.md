# 🪄 해리포터 모험 게임 - 마법사의 돌

초등학교 저학년 학생을 위한 인터랙티브 텍스트 어드벤처 게임입니다.

## 🎮 게임 소개

해리포터 1편 "마법사의 돌"을 배경으로 한 선택형 모험 게임입니다. 해리, 론, 헤르미온느 중 한 명을 선택하여 각자의 모험을 경험할 수 있습니다.

## ✨ 게임 특징

- **3명의 주인공 선택**: 해리 포터, 론 위즐리, 헤르미온느 그레인저
- **각 주인공별 10개 이벤트**: 해리포터 1편의 주요 장면을 각 주인공의 관점으로 경험
- **각 이벤트마다 3개 선택지**: 선택에 따라 우정, 용기, 지식 수치가 변화
- **다양한 결말**: 선택에 따라 용기/지혜/우정 결말로 분기
- **1인칭 시점**: 몰입감 있는 스토리텔링
- **초등학생 친화적 디자인**: 큰 글씨와 명확한 UI

## 🎯 게임 방법

1. 주인공을 선택하세요 (해리, 론, 헤르미온느)
2. 각 이벤트에서 3개의 선택지 중 하나를 선택하세요
3. 선택에 따라 스토리가 진행되고 수치가 변화합니다
4. 10개의 이벤트를 완료하면 결말을 확인할 수 있습니다
